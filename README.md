# Breakout Arcade Game

A classic arcade-style Breakout game built with Python and the built-in `turtle` module, designed as part of a professional portfolio project.

## Features

- **Interactive Gameplay:** Control a sliding paddle using keyboard arrow keys to bounce the ball and destroy the grid of colored bricks.
- **Dynamic Collision System:** Accurate coordinate and distance checks for bouncing the ball off walls, the paddle, and individual bricks.
- **Score Tracking:** Real-time scoreboard that updates dynamically as each brick is cleared from the board.
- **Game Over State:** Detects when the ball misses the paddle and displays a game-over prompt.

## Tech Stack

- **Python** (Core Game Logic)
- **Turtle Module** (Graphics & Event Listening)
